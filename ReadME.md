## How to Run
1. Open the project folder in VS Code.
2. Open the terminal in VS Code.
3. Make sure Python is installed by running:

```bash
python --version
```
4. Install NumPy:
   pip install numpy

5. Make sure your Python file contains:
   import numpy as np   

6. Run the Python file for the required task using the commands below.
7. Check the output in the terminal.
